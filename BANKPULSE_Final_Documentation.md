# BANKPULSE v2 - Final Documentation

Project: Temporal Data Mining Framework (Adapted)
Status: Advanced Research Prototype
Repo: https://github.com/GithubUserWTFAreYouReadingMyData/BANKPULSE

## Summary
BankPulse v2 uses transaction data with multi-scale temporal windows, customer-relative features, customer-level splits, calibration, and ablations. Fraud is proxy.

## Ablation
A1_snapshot PR-AUC 0.0139, A2_engineered PR-AUC 0.5785 - temporal features add significant value.

## Key Files
src/, reports/, models/, app_v2_improved.py, README.md

## Limitations
Proxy, row-based rolling, Transformer untrained, forward-chaining partial, operational metrics need expansion.
