# BankPulse v2 - Temporal Early Warning with Transaction Sequences

Aligned to original proposal: multi-scale temporal windows, customer-relative change detection, compact Transformer on sequences, baseline-first, calibrated & explainable. Human-in-the-loop only.

Dataset: santosh3110/credit_card_fraud_transactions (~1.05M transactions, per-card history, timestamps, amounts, categories). Fraud as proxy for anomalous/at-risk activity (documented as proxy).
